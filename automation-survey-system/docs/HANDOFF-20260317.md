- `psycopg2` 설치 금지 — Windows CP949 환경에서 UnicodeDecodeError 발생
- DATABASE_URL 비밀번호에 `@` 포함 시 반드시 `%40`으로 URL 인코딩
- `dc.leemock.local` DNS 미등록 → `ad1.leemock.local` 사용
- LDAP 사용자 검색: `OU=Users,...` 아님 → `DC=leemock,DC=local` SUBTREE
- PostgreSQL 사용자명: `postgres` (s 있음, `postgre` 오타 주의)
